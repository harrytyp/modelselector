🔒 Privacy & Legal

ModelSelector is a static client-side application

No Data Collection. ModelSelector runs entirely in your browser. No cookies, no tracking scripts, no analytics, no telemetry. All data processing — VRAM calculations, speed simulation, benchmark comparison — happens locally on your machine.

External Requests. When you use the "Import from Hugging Face" feature, a request is sent directly to the Hugging Face API to search for models. No data about you or your hardware is transmitted.

Model Data. All model specifications, benchmark scores, and GPU hardware data are fetched from public APIs (Hugging Face, LiveBench, EvalPlus, BenchLM, TechPowerUp) and cached in a local JSON file. No user data is ever sent to any third party.

Disclaimer. Speed estimates are physics-based approximations. Actual performance depends on your specific hardware configuration, driver version, cooling, system load, and software implementation. Use these estimates as a guide, not a guarantee.
